# 名词与公式说明（报告用）

两种用途：
- **技术版**的第 0 节“读前须知”：从“A. 名词表”里挑出本报告实际用到的词，原样或按本报告数据改写；从“B. 公式说明”里挑出用到的公式。没用到的词不要放。
- **通俗版**：按“C. 通俗说法对照”把术语换成日常说法，正文里不出现左列的词。

## A. 名词表（技术版第 0 节用）

每条一句定义，必要时加一句“在本报告里是多少”。

| 名词 | 一句话解释 |
|---|---|
| 叙事 | 市场对公司未来能赚多少钱的整体想象。股价就是这段想象折算到今天的价值。 |
| 隐含叙事 / 隐含预期 | 从现在的股价倒推出来的“市场相信的未来”。不是本报告的预测，是价格里已经包含的假设。 |
| 业绩天花板 / 终局利润 / 长期稳态利润 / 中周期利润（T） | 公司发展到成熟或周期平均状态后，每年能稳定赚到的净利润（亿元）。四个说法指同一个东西：成长股常说天花板，周期股常说中周期或稳态。 |
| m（天花板倍数） | 终局利润 ÷ 某一年的利润。m=3 表示长期利润是那一年的 3 倍；m<1 表示长期利润会比那一年低。每次出现都要写明“相对哪一年”。 |
| E0 / E1 | E0 是当年的净利润（全年未结束时用估计值），E1 是下一年的一致预期净利润。 |
| 扣非 / 归母 | 归母：归属上市公司股东的净利润。扣非：再去掉卖资产、投资收益等一次性项目后的利润，更能反映主业。 |
| 一致预期 | 多家券商对同一年利润预测的中位数或平均数。 |
| 动态 PE / PE1 | 市值 ÷ 下一年预期利润（E1）。 |
| 折现率 r | 投资者持有这只股票要求的年回报率。未来的钱按 r 打折换算成今天的钱。A 股默认 10%，美股 8%。 |
| n（到达年数 / 回落年数） | 利润从现在走到终局利润要几年。上升时叫到达年数，周期见顶后下降时叫回落年数。 |
| 重定基期 | 计算时把下一年当作起点：假设第 1 年拿到 E1，之后每年按同一比例走到终局利润。用于下一年利润和今年差别很大的情况。 |
| 模型 A / 模型 B | 模型 A 用于已经盈利的公司，利润按固定比例逐年变化到终局。模型 B 用于还没盈利的公司，利润按固定金额逐年增加到终局。 |
| K（市值速算倍数） | 模型 B 里“市值 ÷ 终局利润”的倍数，用来从市值倒推终局利润。 |
| 经营市值 | 总市值减去与主业无关的资产（多余现金、持有的其他公司股票等），即市场给主业的价格。 |
| 横着拔估值 | 市场上调了终局利润（天花板变高），股价上涨且可持续。 |
| 竖着拔估值 | 市场下调了折现率（愿意接受更低回报），股价上涨，但会回落。 |
| alpha / beta | alpha：来自公司自身叙事变化、能跑赢指数的收益。beta：跟着大盘或行业一起涨跌的收益。 |
| 叙事兑现期 / 变化期 | 兑现期：业绩按预期走，股价只赚折现率，大致跟指数走。变化期：市场在改写终局利润，股价明显跑赢或跑输。 |
| 叙事打满 | 股价已经把最乐观的终局都算进去了，再往上需要新的故事。 |
| 主变量 | 最能提前反映利润预测变化的那个业务指标，如批价、订单、商品价格。 |
| 情景 / 概率链 | 列出几种终局（悲观、中性、乐观），每种给一个概率。概率链是把一个情景拆成几步，每步的概率相乘。 |
| 合理市值 | 各情景对应的市值按概率加权后的结果。 |
| 根本矛盾 / 准入测试 | 根本矛盾：市场价格里的假设和数据冲突、或市场没有定价的事件。准入测试：如果它被证实，股价应该明显变动；不会变动的就不算。 |
| 证伪信号 | 出现后说明本报告判断错了的具体数据或事件。 |
| 拍卖机制 / 截距漂移 | A 股难以做空，股价由最乐观的那批买家决定，所以常高于平均预期。高出的部分叫截距漂移，分歧越大、流动性越好，漂移越大。 |
| EVA（经济增加值） | (投资回报率 − r) × 投入本金。回报率高于 r 才创造价值，等于 r 时增长不加分。 |
| AH 价差 | 同一公司 A 股价格相对 H 股价格的溢价。 |

## B. 公式说明（技术版第 0 节用）

先写一句话的总思路，再列用到的公式，每个符号都说明含义。示例写法：

> 总思路：股价 = 未来每年利润折算到今天的总和。假设利润先用 n 年走到终局利润 T，之后每年都是 T；每年的钱按折现率 r 打折。这样，只要知道 T 和 r，就能算出公司值多少；反过来，知道市值，也能倒推出市场相信的 T。

- **模型 A（价值倍数）**：V = P/E0 = Σ_{t=1..n} [m^(1/n)/(1+r)]^t + m/[r(1+r)^n]。第一项是走向终局那 n 年利润的折现和，第二项是终局之后永续利润的折现值。P 是市值，m = T/E0。
- **动态 PE**：PE1 = V / m^(1/n)，即用下一年利润算的市盈率。
- **重定基期（主口径）**：第 1 年利润 = E1，此后 n 年从 E1 按固定比例走到 T，之后恒为 T。合理市值 = [E1 + E1·V(T/E1, r, n)] / (1+r)，V 就是上面模型 A 的式子，只是把 m 换成 T/E1。
- **模型 B**：K = (1/n)Σ t/(1+r)^t + 1/[r(1+r)^n]；隐含终局利润 = 市值 / K。
- **合理市值** = Σ 情景市值 × 情景概率；相对现价 = 合理市值 ÷ 现价市值 − 1。
- **拍卖机制**（只做定性）：y = μ + σ·Φ⁻¹(1 − s/x)，y 是成交价，μ 是平均预期，σ 是分歧程度，s 是流通盘能容纳的资金，x 是关注这只股票的资金。

用一个本报告里的数字带一遍，比只给公式好懂：例如“现价市值 919 亿、E1 175 亿、r 10%、n 3 年，倒推出 T ≈ 76 亿”。

## C. 通俗说法对照（通俗版用）

左列的词不出现在通俗版正文里。确实需要时，用右列的说法，或直接说数字。

| 术语 | 通俗版说法 |
|---|---|
| 隐含 m / 隐含叙事 / 隐含终局利润 | “按现在的股价，市场相当于相信公司长期每年能赚约 X 亿元” |
| 合理 m / 合理终局利润 | “本报告估计公司长期每年大约能赚 X 亿元” |
| 折现率 r | “买这只股票每年期望拿到约 10% 的回报” |
| n、到达年数、回落年数 | “大约 X 年后利润回到正常水平” / “X 年后长到这个规模” |
| 动态 PE / PE1 | “股价约等于明年利润的 X 倍”（只在必要时用一次） |
| E0 / E1、扣非、一致预期 | “今年利润约 X 亿、明年券商平均预计 X 亿”（只说一次“去掉一次性收入后”） |
| 经营市值 | “扣掉公司账上的现金和持有的其他股票，市场给主业的价格约 X 亿” |
| 横着拔估值 / 天花板打开 | “市场上调对公司长期赚钱能力的判断” |
| 竖着拔估值 | “市场整体情绪变好，愿意给更高价格（这种上涨容易回吐）” |
| alpha / beta | “靠公司自己跑赢大盘” / “主要跟着行业和大盘涨跌” |
| 叙事打满 | “好消息已经全部反映在股价里” |
| 主变量 | “最值得盯的一个数：X” |
| 情景 / 概率加权 | “三种可能：差的、一般的、好的，可能性分别约为 X%、Y%、Z%” |
| 根本矛盾 | “市场可能看错的地方” |
| 证伪信号 | “出现这些情况，说明本报告的判断错了” |
| 拍卖机制 / 截距漂移 | “A 股不容易做空，股价常被最乐观的买家抬高” |
| EVA | “赚的钱是否超过资金成本” |
