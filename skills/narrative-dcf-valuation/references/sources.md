# 数据去哪找

所有数字记下日期和链接；搜索结果摘要不算来源，要打开原文。shell 通常不能联网，用 WebSearch / WebFetch。

| 需要什么 | 去哪找 | 搜索写法示例 |
|---|---|---|
| 最新股价、总市值 | 财经新闻当日行情稿、券商报告首页“基础数据” | “公司名 股价 市值 <月> <年>” |
| 当年与下一年盈利预测 | 东方财富研报 PDF（pdf.dfcfw.com）、券商点评摘要 | “公司名 <年> 归母净利润 预测 研报”“公司名 盈利预测 上调” |
| 历史时点的预测（修正轨迹） | 同上，按日期找不同时点的报告；报告首页有当时收盘价和总市值 | “公司名 <年> 年报点评”“公司名 <年> 三季报点评” |
| 历史高低点与当时估值 | 财联社、界面等行情复盘稿；券商报告“52周最高/最低价” | “公司名 历史最高 市值”“公司名 <年> 最低 PE” |
| 业务拆分、订单、指引、资本开支、分红回购 | 季报/年报新闻稿、业绩说明会、投资者开放日实录 | “公司名 三季报 在手订单 指引”“公司名 投资者开放日” |
| 客户集中度、地区收入 | 年报“前五名客户”“分地区”，财经媒体对年报的解读 | “公司名 前五大客户 占比 <年>” |
| A/H 价差 | 智通财经“智通AH统计”（每日）、AH 溢价指数新闻 | “智通AH统计 <月>月<日>日”“AH股溢价指数 <月> <年>” |
| 政策、法规、诉讼的截止日 | 律所分析（Ropes & Gray、Greenberg Traurig、DLA Piper 等）、法规原文 | “公司英文名 + 法规名 + deadline”“<法规名> implementation timeline” |
| 商品价格（周期股） | 交易所、行业协会、财经新闻 | “<商品> 价格 <月> <年>”“<商品> 均价 季度” |
| 行业空间与同行对比 | 券商行业深度、公司披露的第三方数据（Frost & Sullivan 等） | “<行业> 市场规模 <年>” |
| 指数对比 | 券商报告首页“股价走势/相对表现”图注、行情复盘稿 | “公司名 跑赢 沪深300 <年>” |

拿不到 Wind 一致预期时，写明用的是哪几家券商、哪天的预测，并标为近似值。
