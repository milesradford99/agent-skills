# 人物与命运

开书第四步写全书故事、排分卷纲、卷末对照故事框架时读这一份。它管的是一本书最后让人记住什么：每个重要人物被带到了哪里。单章怎么写情绪，在写作规则里。

## 一、一条原则

**给每个重要人物找出他最在乎的那一处，结局就落在那一处上。**

“最在乎的那一处”是下面这几样里最能定义他的一样：他最想要的东西；他认定的“我是谁”（最骄傲、最自尊、最讲义气）；他最看重的人或规矩；他最怕变成的样子。一个人物只挑一样，写成一句话，比如“他认定自己从不欠人”“她这辈子只想一家人坐在一张桌上吃饭”。

读者的情绪跟着人物在乎的东西走。同样是受伤、失败、死，打在他不在乎的地方，读者只觉得出了一件事；打在他最在乎的那一处，读者就觉得这是他的命。所以设计命运，先问的不是“这里该发生什么大事”，而是“这件事碰到了谁最在乎的那一处，往哪个方向推”。

## 二、七个方向

同一个“最在乎”，结局往不同方向推，读者得到的东西完全不同。下面的例子都是为说明编的。

| 方向 | 怎么推 | 读者得到 | 例子 |
|---|---|---|---|
| **打碎** | 和他最在乎的正相反，往坏处 | 虐、痛、意难平 | 认定自己从不欠人的人，最后欠了一条还不上的命 |
| **逆袭** | 和他的处境正相反，往好处 | 爽 | 全村最被看不起的药童，最后人人求他开方 |
| **成全** | 他变成了自己最不像的那种人，往好里变 | 燃、泪 | 一辈子只顾自己的掌柜，最后把粮仓打开 |
| **坚守** | 他没变，守住了，代价是别的全没了 | 敬 | 不肯低头的人到最后也没低头，输了一切 |
| **圆满** | 他得到了，但得到的是他真正需要的那个版本 | 暖 | 只想一家人团圆的姑娘，最后和一群没血缘的人坐成了一桌 |
| **报应** | 他用来对付别人的东西，回到他自己身上 | 解气 | 靠算计往上爬的人，栽在自己布的局里 |
| **错位** | 他的“最”被所有人误读 | 好笑、反差 | 最胆小的人，被一屋子高手当成隐世大能 |

**一本书怎么配。** 多数网文的配法是：主角走逆袭（或圆满）这条主轴；重要配角里放一两个打碎或坚守，给全书分量；反派走报应；在某一卷的高潮用一次成全，把情绪推到顶。全书都走打碎，读者会累；全书都走逆袭，读者会腻。配法由作者定，它就是这本书的情绪底色：读者主要是来这里得到爽、痛、燃还是暖。

**方向可以在路上转。** 一个人物前半本像要走打碎，最后走成了成全，这种转折往往最好看；但转的那一下要由他自己的选择触发，不是作者改主意。

## 三、不靠这根轴的手法

- **写后果，不写事件。** 最重的情绪常常不放在事情发生的那一刻，而放在之后：一个物件、一句话、一个空出来的位置。比如一群人里年纪最小的那个，多年以后在一排墓碑前说“现在我比你们都大了”。这一句比把每个人怎么死都写一遍更重。
- **对照。** 把相反的两个“最”放在两个人身上，让他们在同一件事上做出相反的选择，互相照出对方。
- **读者知道，人物不知道。** 读者早一步知道结局在等着，看人物一步步走过去。
- **反着写。** 用热闹的场面写悲伤，用平静的日常写一个人已经变了；在读者以为要爆发的地方收住。

## 四、怎样让命运成立

1. **由他自己推过去。** 结局要从他最在乎的那一处长出来：骄傲的人跪下，得是他的骄傲一步步把他逼到了只能跪的地方；算计的人被反噬，得是他自己的算计留下了口子。外面掉下来的灾祸只能当导火索，不能替他做决定。检查办法：把结局那一刻他做的选择写成一句话，看这句话能不能从他“最在乎的那一处”推出来。推不出来，就是作者在替他选。
2. **提前埋。** 他最在乎的那一处，要在前面被读者看清楚，最好被试探过一两次（差一点就破、差一点就成），读者才会在结局时觉得“早该想到”。埋法照伏笔记：写进 `记录-伏笔.md`，涉及这个人物。
3. **一卷推一步。** 命运不是结局那一章才发生的事。每一卷的高潮，至少要让一个重要人物离他的终局近一步，或者被逼着在两条路之间选一次。
4. **代价要真。** 打碎和坚守的代价不能在后面被轻易收回（人死了又被救活、失去的又原样回来）。要收回，收回本身得付更大的代价，而且读者要觉得值。

## 五、常见的坑

- **为虐而虐。** 结局和人物最在乎的那一处没关系，只是越惨越好。读者会觉得作者在拿人物出气。
- **不由人物推。** 意外、天灾、作者需要，替人物做了决定。检查办法见上一节第 1 条。
- **全书一个调子。** 所有重要人物都走同一个方向，读者麻木。
- **踩读者的雷。** 网文读者对“虐主”、主角长期憋屈、感情线被拆散格外敏感，付费追读靠的是期待感。主角要走打碎或长期坚守的，开书时就和作者说清楚这个风险，由作者定。
- **方向写成了标签。** “他是悲剧人物”不是方向。方向要写清他最在乎什么、最后怎样、是哪个选择把他带过去的。
- **结局没有对准那一处。** 人物死得很惨，但他最在乎的东西安然无恙，读者只觉得惨，不觉得痛。

## 六、在流程里怎么用

- **人物档案。** `03-人物.md` 每个重要人物有两行：“最在乎、最自认的”（一句话）和“终局方向”（七个方向之一，加一句他怎样由自己的选择走到那里）。终局方向由作者定；没定之前写“待定”，你的推荐放在开书记录里，不写进人物档案。
- **开书第四步。** 写全书故事时，给主角和三四个重要人物各推荐一个方向，再推荐全书的情绪底色（主轴是什么、配角里放什么、反派怎样），作为方向关卡交给作者，见 `references/开书.md` 4.2。
- **分卷纲。** 每卷写清：这一卷的高潮碰到了谁最在乎的那一处，往哪个方向推了一步，见 `references/排细纲.md` 第二节。
- **卷末。** 对照每个重要人物离他的终局走了多远，有没有人一卷都没动，见 `references/卷末和完本.md` 第 4 步。
- **写正文。** 处境卡里写到某个人物时，想一想这一场有没有碰到他最在乎的那一处；碰到了，这就是最值得展开的那场戏。

终局方向是作者的决定。作者改了主意，照改，旧的写进 `记录-废弃设定.md`。
